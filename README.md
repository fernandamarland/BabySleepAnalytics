# Baby Sleep Analytics 
Projeto desenvolvido para registrar e analisar a rotina de bebês, permitindo acompanhar informações como sono, mamadas, alimentação e vacinas por meio de indicadores e gráficos. 
## Tecnologias
- Python
- Git
- GitHub
- SQLite
- Streamlit
- Matplotliob
## Objetivos 
Trasformar dados da rotina do bebê em informações úteis para ajudar pais e resposáveis na tomada de decisões.

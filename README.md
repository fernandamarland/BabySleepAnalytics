# 👶 Baby Sleep Analytics

Sistema desenvolvido em Python para auxiliar pais e responsáveis no acompanhamento da rotina do bebê, permitindo registrar informações importantes como sono, mamadas, alimentação, vacinas e dados cadastrais.

## 📌 Objetivo

O projeto foi desenvolvido com o objetivo de colocar em prática conhecimentos em Python, SQLite, SQL, Git e GitHub, simulando um sistema real de gerenciamento de informações.

A ideia surgiu ao perceber como é difícil acompanhar diariamente informações importantes do bebê, como horários de sono, mamadas, alimentação e vacinas.

## ⚙️ Funcionalidades

- Cadastro de bebês
- Visualização dos bebês cadastrados
- Registro de sono
- Histórico do sono
- Registro de mamadas
- Histórico das mamadas
- Registro de alimentação
- Histórico da alimentação
- Registro de vacinas
- Histórico das vacinas

Todos os dados são armazenados em um banco de dados SQLite.

---

## 🗄️ Banco de Dados

O sistema utiliza SQLite para armazenar todas as informações do bebê.

As tabelas utilizadas são:

- Bebês
- Sono
- Mamadas
- Alimentação
- Vacinas

## ▶️ Como executar

1. Clone o repositório

```
git clone https://github.com/SEU-USUARIO/BabySleepAnalytics.git
```

2. Acesse a pasta

```
cd BabySleepAnalytics
```

3. Execute o projeto

```
python src/main.py
```
